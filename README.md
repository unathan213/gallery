# Lens & Light Studio

Marketing website for a wedding and events photography studio.

## About

Five-page static site built to showcase a photographer's portfolio and convert
enquiries into bookings. The gallery is the centrepiece — image-heavy pages need
to stay fast, so everything is served as plain static assets with no framework
or build step.

## Pages

| Page | Purpose |
|---|---|
| `index.html` | Landing page — hero, featured work, call to action |
| `gallery.html` | Full portfolio gallery |
| `services.html` | Services and package pricing |
| `about.html` | Studio background and photographer bio |
| `contact.html` | Enquiry and booking form |

## Features

- Responsive across mobile, tablet, and desktop
- Image gallery with video assets in `videos/`
- Services and package tiers
- Contact and booking enquiry form

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

No build step and no dependencies — open `index.html` in a browser, or serve the
folder with any static host.
